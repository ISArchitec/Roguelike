## Описание системы

### 1. Концепция

**«Бюро»** — пошаговый рогалик (roguelike), в котором игрок управляет
персонажем, чьи данные были случайно стёрты из электронной системы учёта
граждан. Цель персонажа — собрать комплект документов и вернуть себе
статус гражданина.

Игра построена на процедурно сгенерированных уровнях, представляющих кабинеты
ведомств. Каждый уровень — это набор коридоров с врагами (людьми в
очереди). Финальная цель — получить паспорт на последнем уровне.

### 2. Основные сущности

| Сущность               | Описание                                                       |
|------------------------|----------------------------------------------------------------|
| **Персонаж**           | Управляемый игроком герой с набором характеристик              |
| **Уровень**            | Отдельный кабинет — сетка коридоров с врагами                  |
| **Секция**             | Блок из 5 уровней, последний — босс                            |
| **Враг**               | NPC в очереди, препятствующий продвижению                      |
| **Босс**               | Усиленный враг с особым паттерном атак                         |
| **Справка**            | Пассивный модификатор характеристик (награда за обычный уровень) |
| **Удостоверение**      | Активная способность с кулдауном (награда за босса)            |
| **Предмет из рюкзака** | Расходник (восстановление HP или временный бафф)               |

### 3. Характеристики персонажа и врагов

| Характеристика            | Назначение                          |
|---------------------------|-------------------------------------|
| **Ментальное здоровье**   | Здоровье персонажа. Когда оно становится равно нулю, попытка завершается |
| **Внутреннее равновесие** | Защита персонажа |
| **Уверенность в себе**    | Атака персонажа |
| **Реакция**               | Скорость персонажа - число действий за ход, которые он может совершить |

### 4 Игровой цикл и описание механик

Игрок проходит несколько ведомств, каждое из которых представляет отдельную секцию уровней

Внутри каждой секции находится 4 обычных уровня, и уровень с боссом. Для того,. чтобы пройти уровень, необходимо победить всех врагов на нём. После победы над всеми врагами обычного уровня, персонаж получает справку - предмет, увеличивающий характеристики персонажа. После победы над боссом, персонаж получает на выбор одно из двух удостоверений - предметов, которые могут совершать атаку по области. С собой можно переносить сколько угодно удостоверений, но на каждом уровне можно использовать только одно

Внутри каждого уровня сражения проходят по шагам. Очерёдность передаётся по кругу, первым начинает игрок, затем все враги. В свой ход можно сделать определённое число действий, определяемое скоростью. Действиями могут быть:

1. Перемещение в соседнюю клетку
2. Атака - осуществляется перемещением в клетку, где находится враг
3. Специальная атака - осуществляется использованием удостоверения. После неё удостоверение нельзя использовать некоторое число ходов (зависящее от удостоверения)
4. Использование одноразового предмета из рюкзака. Такие предметы могут давать временный (на один уровень) бонус, либо восстанавливать здоровье. Такие предметы случайно выдаются персонажу в начале игры, и не могут быть получены иным способом
