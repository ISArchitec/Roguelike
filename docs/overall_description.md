## Описание системы

### 1. Концепция

**«Бюро»** — пошаговый рогалик (roguelike), в котором игрок управляет
персонажем, чьи данные были случайно стёрты из электронной системы учёта
граждан. Цель персонажа — собрать комплект документов и вернуть себе
статус гражданина.

Игра построена на процедурно сгенерированных уровнях, представляющих кабинеты
ведомств. Каждый уровень — это набор коридоров с врагами (людьми в
очереди). Финальная цель — получить паспорт на последнем уровне.

### 2. Основные сущности

| Сущность               | Описание                                                       |
|------------------------|----------------------------------------------------------------|
| **Персонаж**           | Управляемый игроком герой с набором характеристик              |
| **Уровень**            | Отдельный кабинет — сетка коридоров с врагами                  |
| **Секция**             | Блок из 5 уровней, последний — босс                            |
| **Враг**               | NPC в очереди, препятствующий продвижению                      |
| **Босс**               | Усиленный враг с особым паттерном атак                         |
| **Справка**            | Пассивный модификатор характеристик (награда за обычный уровень) |
| **Удостоверение**      | Активная способность с кулдауном (награда за босса)            |
| **Предмет из рюкзака** | Расходник (восстановление HP или изменение характеристик)               |

### 3. Характеристики персонажа и врагов

| Характеристика            | Назначение                          |
|---------------------------|-------------------------------------|
| **Ментальное здоровье**   | Здоровье персонажа. Когда оно становится меньше либо равно нулю, попытка завершается |
| **Внутреннее равновесие** | Защита персонажа |
| **Уверенность в себе**    | Атака персонажа |
| **Реакция**               | Скорость персонажа - число действий за ход, которые он может совершить |

### 4 Игровой цикл и описание механик

Игрок проходит несколько ведомств, каждое из которых представляет отдельную секцию уровней

В стандартной игре пять секций. В каждой секции четыре обычных уровня и уровень с боссом. После победы над всеми врагами обычного уровня на случайной свободной клетке появляется справка. После победы над боссом игрок выбирает одно из двух случайных удостоверений, и выбранное удостоверение также размещается на карте. Награда попадает в инвентарь только при взаимодействии с ней; лишь после подбора уровень считается пройденным. Подбор награды последнего босса завершает игру получением паспорта.

С собой можно переносить сколько угодно удостоверений. В течение уровня игрок может выбрать одно из них, если ещё не выбрал; повторный выбор блокируется до следующего уровня. При переходе активное удостоверение сбрасывается, сами удостоверения остаются в инвентаре.

Сражения проходят по шагам: сначала герой, затем живые враги. Скорость героя определяет число успешных действий за ход. Пустая очередь событий ожидает ввод; неудачное движение или недоступная специальная атака не расходуют действие. После действий всех участников увеличивается `Game.get_ticks()`, по которому рассчитывается готовность удостоверений.

Действиями могут быть:

1. Перемещение в соседнюю свободную клетку.
2. Ближняя атака при попытке перемещения в клетку врага или подбор награды при попытке войти в её клетку. Урон равен `max(0, сила атаки − защита)`.
3. Специальная атака выбранным удостоверением. Следующее применение доступно через заданное удостоверением число тиков.
4. Использование одноразового предмета из рюкзака. Модификатор прибавляется к характеристикам героя, предмет удаляется. Сброса модификатора при переходе уровня сейчас нет. Предметы случайно выбираются из конфигурации в начале игры с повторениями; далее рюкзак не пополняется.
5. Завершение хода с пропуском оставшихся действий.

Обычные враги и боссы используют `IMonsterStrategy`. Текущая `SimpleMonsterStrategy` строит путь к герою; босс хранит одну атаку по области, но эта стратегия пока не выбирает её применение.

### 5. Интерфейс и сохранения

Текущий интерфейс — текстовая консоль (`main.py`). Команды движения: `w/a/s/d`, специальной атаки: `x`, завершения хода: `end`. Команды `i`, `c`, `f` показывают рюкзак, удостоверения и справки; `use N` применяет предмет, `card N` выбирает удостоверение. `save` сохраняет игру, `q` сохраняет её и возвращает в меню. Ввод команд завершается Enter.

Сохранение выполняется на границе тиков, перед очередным ходом героя. Выход, EOF и обрабатываемый SIGTERM запрашивают сохранение; принудительное завершение процесса не гарантирует новое сохранение. Смерть героя аннулирует сохранения только текущей попытки. Формат снимка и конфигурации описан в [configuration.md](configuration.md).
